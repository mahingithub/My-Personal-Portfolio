System Resource Monitor

"The system is primarily a CLI-based OS monitoring tool, while the localhost dashboard provides an additional visualization layer for better usability."

— Project Viva Defense

Dual-Interface Architecture

Built for an Operating System course project, this tool operates on two layers. The Data Collection Layer uses psutil to gather hardware metrics, which are then processed and sent to either the rich CLI dashboard or the Flask-powered Web API.

CLI Dashboard

  • Real-time CPU & per-core sparklines
  • Memory (RAM + Swap) usage bars
  • Network upload/download speeds
  • Interactive process list sorting
  • Cyberpunk hacker-style neon theme

Web Dashboard

  • Live-updating Chart.js graphs
  • Dark-themed UI aesthetics
  • Process table with sort/filter
  • Auto-refresh every 1 second
  • Full REST API backend

Technologies

Python 3.7+ Flask psutil rich (TUI) Chart.js REST API

Compatibility

macOS
Linux (Ubuntu/Kali)
